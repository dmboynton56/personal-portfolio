# LLM Advisor Architecture

## Runtime components

### Configuration layer

`Settings.load()` in `src/core/config.py` sets watchlist, risk caps, session windows, and LLM cadence/model defaults.

### Signal layer

`STDEVThresholds` in `config/thresholds.py` defines base MR/TC arm and trigger boundaries plus ATR/risk filters. Trade signals come from z-score logic, not from the premarket ML classifier.

### Orchestration layer

`src/live/loop.py` controls feature updates, threshold evaluation, timed market analysis, optional trade validation, execution attempts, tick logging, and persistence.

### Premarket ML layer

`src/data_processing/daily_bias_computing.py` loads per-symbol sklearn artifacts from `llm-advisor/models/{SYMBOL}_daily_bias.pkl` (+ label encoder + feature names). Committed placeholders are generated by `scripts/export_minimal_bias_models.py`; production models should replace these before treating ML bias as authoritative.

### Storage and telemetry layer

**BigQuery (cold path):** dataset `trading_signals` (`GCP_DATASET_ID` secret; default in code). Tables include `trades`, `trade_signals`, `live_loop_logs`, `daily_bias`, `positions`, and related premarket/analysis tables (`src/data/bigquery_storage.py`).

**Supabase (serving path):** migration `005_llm_advisor_telemetry.sql` defines:

- `llm_advisor_backtest_runs` — one row per trading day (`run_date` PK)
- `llm_advisor_backtest_trades` — per-trade rows (`trade_uid` PK)
- `llm_advisor_runtime_heartbeats` — loop freshness

EOD workflow (`scripts/run_eod_aggregate.py`) upserts from live-loop artifacts into these tables; `scripts/sync_bq_to_supabase.py` optionally merges a rolling BQ window. Inventory: `plans/docs/supabase_tables/llm_advisor_telemetry_tables.json`.

The portfolio API (`GET /api/llm-advisor/metrics`) reads Supabase in production. Local artifact fallback is non-production only.

## Daily automation chain

1. **Premarket** (~09:20 ET) — GCP Cloud Scheduler → `premarket.yml` → `premarket_context.json` artifact
2. **Live loop** (~09:27 ET) — `live_loop.yml` waits for same-day premarket artifact → runs 09:30–12:00 ET session → uploads `llm-advisor-daily-news-*` artifact; writes BQ when `STORAGE_ENV=bq`
3. **EOD aggregate** — auto `workflow_run` after successful Live → downloads triggering artifact → `run_eod_aggregate.py` → Supabase upsert (+ optional BQ sync)

Manual EOD backfill: `workflow_dispatch` with `live_loop_run_id` and optional `date`.

## GitHub secrets (llm-advisor repo)

Required for EOD → Supabase: `SUPABASE_DB_HOST`, `SUPABASE_DB_PORT`, `SUPABASE_DB_NAME`, `SUPABASE_DB_USER`, `SUPABASE_DB_PASSWORD`, `GCP_DATASET_ID`, plus existing `GCP_PROJECT_ID`, `GCP_SA_KEY`, Alpaca, and LLM keys.

Optional: `PORTFOLIO_METRICS_URL`, `EOD_STRICT_TELEMETRY=1`.

## Architecture caveat

Legacy `config/settings.py` may differ from runtime defaults; prefer `src/core/config.py` and active workflow wiring for operational claims.
