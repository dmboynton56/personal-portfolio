# Metric Definitions

## Sports Edge Metrics

### `edge_pts`
Formula:
`edge_pts = my_spread - book_spread`

Interpretation:
- Positive: model is less bullish on home team than market line.
- Negative: model is more bullish on home team than market line.
- Magnitude: absolute value reflects disagreement size in points.

### `spreadHit` (completed games)
For a completed game:
- `actual_margin = home_score - away_score`
- `spreadHit = actual_margin > -my_spread`

This checks whether the model-side spread condition was met under the app's home-perspective convention.

### Spread Hit Rate
`spread_hit_rate = spread_hits / completed_games`

Notes:
- Undefined when there are no completed games in the selected slice.
- Sensitive to sample size and should be tracked by week/season and model version.

### Data Freshness Fields
- `prediction_ts`: timestamp of latest model prediction selected for game
- `odds_ts`: timestamp of latest odds snapshot selected for game
- `updatedAt` (API payload): timestamp when API response was produced

## NBA Hall of Fame Metrics

### `hofProbability`
Model-estimated probability-style score from 0 to 1.

### Confidence Buckets
Suggested mapping in UI context:
- Very High: very likely candidate
- High: strong candidate
- Medium: borderline
- Low/Very Low: unlikely under current feature profile

### Feature Importance Context
Higher influence features typically include career impact metrics, award history, and longevity.

## Feature Rationale (The "Why")

### Rest Days and Fatigue
The model cares about rest days because cumulative fatigue significantly impacts team efficiency. Teams playing on the second night of a back-to-back (B2B) or a third game in four nights (3in4) typically show a measurable drop in defensive intensity and shooting accuracy. 

### `opp_strength_differential` (SOS Adjustment)
Raw PPG (Points Per Game) is a misleading metric because it doesn't account for who a team has played. `opp_strength_differential` adjusts a team's performance based on the quality of their opponents. A high-scoring game against a top-tier defense is weighted more heavily than the same score against a bottom-tier defense. This "Strength of Schedule" adjustment is essential for identifying true betting edges where the public might be overvaluing raw stats.

### Form Metrics (3-game vs 10-game)
Short-term form (3-game) captures recent momentum, injuries, or rotation changes. Long-term form (10-game) provides a more stable baseline of a team's true talent level. The model compares these windows to identify teams that are currently overperforming or underperforming relative to their season average.
