# Data Dictionary & BigQuery Schema

## Scope
This document provides the canonical schema for the Sports Edge BigQuery environment. The chatbot uses this to generate SQL queries.

## Datasets
1. `sports_edge_results`: Contains historical outcomes and calculated performance metrics.
2. `sports_edge_raw`: Contains raw play-by-play, schedules, and team statistics.
3. `sports_edge_curated`: Contains engineered feature snapshots used for model inference.

## Primary Tables (sports_edge_results)

### Table: `game_results`
Use this table for questions about win/loss records, scores, and spread coverage.
- `game_id` (STRING): Unique identifier.
- `league` (STRING): 'NFL' or 'NBA'.
- `season` (INT64): Year of the season.
- `game_date` (DATE): Date of the game.
- `actual_home_points` (INT64): Final score for the home team.
- `actual_away_points` (INT64): Final score for the away team.
- `actual_home_win` (BOOL): True if home team won.
- `actual_home_margin` (INT64): (Home Points - Away Points).
- `model_version` (STRING): The version of the model used for predictions.

## Primary Tables (sports_edge_raw)

### Table: `raw_nba_game_logs`
Use this for detailed team-level performance trends.
- `team` (STRING): Team name.
- `points_scored` (INT64): Points scored by the team.
- `points_allowed` (INT64): Points allowed by the team.
- `net_rating` (FLOAT64): Advanced efficiency metric.

### Table: `raw_schedules`
Use this for upcoming games and schedule lookups.
- `home_team` (STRING)
- `away_team` (STRING)
- `game_date` (DATE)

## Primary Tables (sports_edge_curated)

### Table: `feature_snapshots`
Use this for questions about model features like rest days.
- `rest_home` (FLOAT64): Days of rest for home team.
- `rest_away` (FLOAT64): Days of rest for away team.
- `rest_differential` (FLOAT64): Difference in rest between teams.
- `opp_strength_differential` (FLOAT64): SOS adjustment.

## Join Logic
- Tables can be joined on `game_id`.
- League filters (`league = 'NBA'` or `league = 'NFL'`) should always be applied.
- Season filters (`season = 2025`) are recommended for performance.
