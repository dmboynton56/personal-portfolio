# Published notebook HTML (portfolio)

Notebook HTML exports from `sports-edge` and `llm-advisor` CI (`publish-notebooks` workflows) should be copied or deployed here as static files, for example:

- `sports-edge-*.html` — ATS / calibration / backtest outputs  
- `llm-advisor-*.html` — trade journal, P&L attribution, etc.

Link from project pages via `/notebooks/<filename>.html` once files are present. Until then, project pages can reference live Supabase metrics and the notebook repos on GitHub.
